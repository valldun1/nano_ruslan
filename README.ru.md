# NanoRuslan 🐈🇷🇺

Лёгкий, открытый AI-агент на Python для русскоязычных пользователей.

**Форк:** [HKUDS/nanobot](https://github.com/HKUDS/nanobot) (MIT)
**Экосистема:** Руслан | GoRuslan | NanoRuslan

## Что это

NanoRuslan — сверхлёгкий AI-агент, которым вы действительно владеете. 
Он держит ядро маленьким и понятным, давая всё необходимое для реальной работы:
WebUI, чат-каналы, инструменты, память, MCP, маршрутизацию моделей, автоматизацию.

## Быстрый старт

```bash
pip install nanoruslan
nanoruslan setup
nanoruslan gateway
```

Или без установки — через Docker:
```bash
docker run -it --rm -v ~/.nanoruslan:/root/.nanoruslan ghcr.io/valldun1/nanoruslan
```

## Возможности

- 🤖 **Agent loop** — умный, с памятью и инструментами
- 💬 **18 каналов** — Telegram, Discord, Slack, Email, WhatsApp и другие
- 🖥 **Встроенный WebUI** — красивый дашборд в браузере
- 🔧 **Инструменты** — файлы, терминал, веб, MCP, код
- 🧠 **LLM провайдеры** — любые OpenAI-совместимые + российские (YandexGPT, GigaChat)
- 📦 **Одна команда** — `pip install && nanoruslan gateway`
